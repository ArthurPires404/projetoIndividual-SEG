# 🏋️‍♂️ Sistema de Academia — Projeto Evolutivo Individual

Este projeto é um sistema de gerenciamento de academia desenvolvido em **PHP** com foco na aplicação prática dos conceitos de **Programação Orientada a Objetos (POO)**.

---

## 🎯 Objetivo do Projeto
Representar as interações de uma academia, permitindo a gestão de pessoas (alunos e professores), matrículas, planos, exercícios, treinos e pagamentos.

---

## 🧠 Conceitos de POO Aplicados

- **Abstração:** Modelagem das entidades do mundo real em classes PHP com atributos e métodos específicos.
- **Encapsulamento:** Utilização dos modificadores de acesso (`private`, `protected` e `public`) protegendo os dados das classes e fornecendo getters/setters.
- **Herança:** A classe base `Pessoa` é herdada pelas classes `Aluno` e `Professor`, reaproveitando atributos como nome, CPF e e-mail.
- **Polimorfismo:** Sobrescrita do método `apresentar()` nas classes filhas (`Aluno` e `Professor`), entregando comportamentos especializados para cada tipo de usuário.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** PHP 8.x
- **Interface:** HTML5 & CSS3 (Design Responsivo e Suporte a Dark Mode)
- **Versionamento:** Git & GitHub
